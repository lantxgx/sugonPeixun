# 曙光军训记录开发工作记录

## 2026-08-26：第一阶段功能实现

### 已完成

- 在 `D:\曙光军训记录index` 创建可运行 Node.js 项目。
- 采用 Express 5 + Node 内置 SQLite，减少外部数据库依赖。
- 创建默认活动“2026届应届生集训”和演示“五连”。
- 实现上传二维码对应连队，学员填写姓名、连队、班级后登记。
- 实现姓名、连队、班级标准化：阿拉伯数字和无符号输入会转为“兰天笑+五连+一班”形式。
- 通过 `活动 + 标准化姓名 + 连队 + 班级` 唯一约束规避重复登记；同一姓名不同班级可登记，完全重复时要求联系管理员处理。
- 登记后生成固定注册 token，上传素材始终绑定登记记录和固定连队。
- 实现照片/视频批量上传：最多20个，照片单张20MB，视频单个500MB，默认上传即公开。
- 实现公开相册，家属通过连队浏览二维码直接查看。
- 实现点赞、留言、举报接口和 H5 操作。
- 实现管理员登录、活动/连队创建、二维码生成、素材上架/下架/待审核/驳回和数据统计。
- 增加 Docker、Nginx、环境变量示例和 OpenAPI 接口文档，为公网部署和后续微信小程序预留 API。
