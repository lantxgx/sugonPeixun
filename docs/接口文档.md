# 接口文档

完整 OpenAPI 3.0 定义在项目根目录 `openapi.yaml`。开发时启动服务后，可使用任意 OpenAPI 阅读器导入该文件。

## 主要接口

| 模块 | 接口 | 说明 |
|---|---|---|
| 健康检查 | `GET /api/health` | 服务存活检查 |
| 登记 | `POST /api/registrations` | 用上传二维码 token 登记姓名、连队、班级 |
| 上传 | `POST /api/media/upload` | multipart，字段 `registrationToken` 和最多20个 `files` |
| 公开相册 | `GET /api/public/{publicToken}` | 家属扫码查看已上架素材 |
| 点赞 | `POST /api/media/{id}/like` | 传入匿名设备标识 `deviceKey` |
| 留言 | `POST /api/media/{id}/comments` | 传入 `nickname`、`content` |
| 举报 | `POST /api/media/{id}/reports` | 传入 `reason`、可选 `contact` |
| 管理登录 | `POST /api/admin/login` | 返回 Bearer token |
| 管理素材 | `GET/PATCH /api/admin/media` | 查看和修改上架状态 |
| 管理二维码 | `GET /api/admin/qr/{type}/{token}` | 输出 PNG 二维码 |

所有管理员接口都需要 `Authorization: Bearer <token>`。
