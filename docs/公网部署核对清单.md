# 公网部署核对清单

## 曙光智算资源确认

只有满足以下任一条件，资源才适合直接承载本网站：

- 云服务器/虚拟机拥有公网 IPv4；
- 能绑定弹性公网 IP；
- 平台提供公网网关、负载均衡、Ingress 或应用发布 URL。

如果资源只有内网 IP、Notebook、HPC 任务节点或临时 GPU 容器，不要直接把它当成公网 Web 服务器。可以将 H5/后端部署在普通公网云服务器，曙光资源只提供 AI 计算服务。

## 发布前检查

- [ ] 域名已解析到公网入口
- [ ] 域名已完成中国大陆服务器所需备案
- [ ] HTTPS 证书已安装
- [ ] 公网防火墙仅放行 80/443
- [ ] SSH 只允许管理员来源
- [ ] Nginx `client_max_body_size` 至少为 `500m`
- [ ] `PUBLIC_BASE_URL` 是最终 HTTPS 地址
- [ ] 管理员密码和 `AUTH_SECRET` 已替换
- [ ] `data/` 已挂载到持久磁盘
- [ ] 已设置 SQLite 和素材目录的每日备份
- [ ] 活动高峰前检查磁盘空间和出口带宽

## 高并发建议

当前上传采用 Multer 流式写入磁盘，不把整个文件读入内存，并通过 SQLite WAL 支持并发读写，适合首版和中等规模活动。

如果预计大量学员同时上传大视频，建议将存储升级为对象存储直传：前端先请求预签名 URL，浏览器直接上传对象存储，服务端只接收完成回调和素材元数据。这样可以减少应用服务器带宽、内存和磁盘压力。业务 API、数据库表和前端上传入口已独立，后续可以替换这一层。
