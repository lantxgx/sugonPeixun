# 曙光军训记录操作 SOP

## 一、首次部署

1. 安装 Node.js 22.5+，或安装 Docker。
2. 复制 `.env.example` 为 `.env`。
3. 设置强管理员密码、随机 `AUTH_SECRET`、公网 HTTPS 地址。
4. 本地启动执行 `npm install`、`npm start`；生产环境执行 `docker compose up -d --build`。
5. 用浏览器打开 `/admin`，登录管理后台。

## 二、创建活动和连队

1. 在后台活动与连队区域选择活动。
2. 输入连队名称，例如 `5`、`五连` 或 `第五连`，系统统一保存为 `五连`。
3. 创建成功后会显示上传链接和浏览链接，并显示两张二维码。
4. 下载或截取上传二维码发给学员；把浏览二维码放到家属可访问的宣传物料中。

## 三、学员登记和上传

1. 学员扫描上传二维码。
2. 输入姓名、连队、班级；连队和班级可以输入阿拉伯数字，例如 `5`、`1`，系统会转为 `五连`、`一班`。
3. 登记成功后进入上传页面。
4. 一次选择最多20个照片或视频；照片单张最大20MB，视频单个最大500MB。
5. 点击上传。当前默认直接公开，成功后家属可以在公开相册看到。
6. 同一活动中同名、同连队、同班级的重复登记会被拦截，需要管理员人工确认重名情况。

## 四、家属查看和互动

1. 扫描浏览二维码打开连队公开相册。
2. 可以播放视频、点赞、留言。
3. 发现不适宜内容时，点击举报并填写原因。

## 五、管理员审核

1. 在后台素材审核列表查看上传者、连队、班级、文件大小和当前状态。
2. 默认公开的内容可点击“下架”；下架内容可重新“上架”。
3. 对不合适内容可设置“驳回”或“待审核”。
4. 举报数据通过管理接口查看，处理后标记为 `resolved` 或 `ignored`；留言可标记 `hidden`。

## 六、日常备份

备份以下两个位置：

- `data/training.sqlite`
- `data/media/`

建议每天备份，活动结束后保留一份只读归档。不要直接开放数据库端口，不要把管理员密码写入前端代码。

## 七、故障处理

- 页面打不开：检查容器 `docker compose ps`、服务日志和 Nginx 反向代理。
- 上传失败：检查 Nginx `client_max_body_size`、磁盘剩余空间、单文件大小和服务器超时设置。
- 二维码无法使用：检查二维码链接域名是否正确，以及 `PUBLIC_BASE_URL` 是否为公网 HTTPS 地址。
- 公开相册无内容：确认素材状态为 `published`，并确认扫描的是浏览二维码而不是上传二维码。
