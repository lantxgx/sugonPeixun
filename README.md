# 曙光军训记录

手机网页端优先的集训照片/视频平台。当前版本包含：扫码登记、姓名/连队/班级标准化、固定连队归属、照片视频批量上传、公开相册、点赞、留言、举报、管理员审核上下架、连队二维码和后台统计。

## 运行要求

- Node.js 22.5+（使用 Node 内置 `node:sqlite`，无需额外数据库服务）
- 生产环境建议使用 Linux + Docker + Nginx + HTTPS

## 本地启动

```powershell
npm install
$env:ADMIN_PASSWORD="请替换管理员密码"
$env:AUTH_SECRET="请替换随机密钥"
$env:PUBLIC_BASE_URL="http://localhost:3000"
npm start
```

打开 `http://localhost:3000`，管理后台为 `/admin`。第一次启动会自动创建默认活动“2026届应届生集训”和“五连”演示连队。管理员在后台可以创建其他连队并获取上传/浏览二维码。

默认限制：一次最多 20 个文件；照片单张不超过 20 MB；视频单个不超过 500 MB；上传默认直接上架，管理员可以下架、重新上架、驳回或置为待审核。

## 公网部署

1. 在服务器安装 Docker，复制整个项目目录。
2. 复制 `.env.example` 为 `.env`，设置强密码、随机 `AUTH_SECRET` 和实际 HTTPS 域名。
3. 执行 `docker compose up -d --build`。
4. Nginx 反向代理到 `127.0.0.1:3000`，配置 `client_max_body_size 500m`，并为域名申请 HTTPS 证书。
5. 公网防火墙只开放 80/443；数据库和 3000 端口不要直接暴露，SSH 仅允许管理员来源访问。
6. 定期备份 `data/training.sqlite` 和 `data/media/`。

如果使用曙光/超算互联网资源，需确认资源类型是可登录的云服务器/虚拟机，且具备公网 IP、网关/负载均衡或公网应用发布能力。若只有 Notebook、HPC 任务节点或内网容器，建议把本平台部署在有公网能力的服务器，把 AI 推理作为智算服务调用。
